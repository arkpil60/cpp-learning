# Workflow

1. Read a concise explanation and clarify key concepts.
2. Write the solution independently, without copying ready-made code.
3. Compile with warnings enabled; run representative and edge-case inputs.
4. Debug errors and document important observations.
5. Review and refactor when it improves correctness or clarity.
6. Commit a meaningful, working unit of progress.

Exercises should have understandable names. Each larger exercise may contain its
own `README.md`, source files, and build/test instructions. Avoid committing
compiled binaries, build directories, or secrets.

The `archive/` directory contains historical source code only; its existence does
not imply the corresponding topics are currently mastered.
