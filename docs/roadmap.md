# Learning roadmap

This is a sequence of topics, not a fixed calendar. Scope and pacing are adjusted
according to hands-on assessments.

- [ ] **0. Diagnostics:** verify current knowledge; identify topics to refresh.
- [ ] **1. Fundamentals:** types, initialization, expressions, scope, functions,
      references, `const`, `constexpr`, translation units.
- [ ] **2. Standard library:** strings, containers, iterators, algorithms, files,
      error handling.
- [ ] **3. Object lifetime and memory:** pointers, value semantics, RAII,
      constructors, destructors, copy and move, smart pointers.
- [ ] **4. Program structure:** class design, APIs, CMake, testing, debugging.
- [ ] **5. Generic programming:** templates, concepts, ranges, STL algorithms.
- [ ] **6. Systems topics:** undefined behavior, profiling, concurrency,
      performance, memory representation.
- [ ] **7. Scientific computing:** floating-point accuracy, numerical methods,
      simulations, verification.
- [ ] **8. Independent project:** planning, implementation, tests, documentation.

A completed checkbox means the topic has been demonstrated in independent work,
not merely read or copied.
