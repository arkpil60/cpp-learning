# C++ Roadmap

- [ ] **0. Fundamentals Review:** syntax, types, control flow, functions, arrays.
- [ ] **1. Language Fundamentals:** initialization, expressions, scope, references, `const`, `constexpr`, translation units.
- [ ] **2. Standard Library:** strings, containers, iterators, algorithms, file I/O, error handling.
- [ ] **3. Memory and Object Lifetime:** pointers, value semantics, RAII, constructors, destructors, copy and move semantics, smart pointers.
- [ ] **4. Program Structure:** class design, APIs, CMake, testing, debugging.
- [ ] **5. Generic Programming:** templates, concepts, ranges, STL algorithms.
- [ ] **6. Systems Programming:** undefined behavior, memory representation, profiling, concurrency, performance.
- [ ] **7. Scientific Computing:** floating-point arithmetic, numerical methods, simulations, verification.
- [ ] **8. Independent Project:** design, implementation, testing, documentation.
