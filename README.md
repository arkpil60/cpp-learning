# C++ Learning

A personal workspace for learning **modern C++** through deliberate practice, notes,
experiments, and small working programs.

The main language baseline is **C++23**. Newer language features are introduced when
supported by the available compiler and standard library.

## Repository layout

| Directory | Purpose |
| --- | --- |
| [`docs/`](docs/) | Learning roadmap, progress tracking, workflow, and tooling |
| [`notes/`](notes/) | Explanations and examples written while learning |
| [`practice/`](practice/) | Exercises written and tested independently |
| [`experiments/`](experiments/) | Small technical investigations and prototypes |
| [`archive/`](archive/) | Historical work preserved for reference |

## Learning approach

- Understand a concept before relying on it in a larger program.
- Write, compile, run, test, and review real C++ code.
- Prefer standard library facilities and explicit ownership.
- Revisit old topics through new problems, not blind repetition.
- Treat archived solutions as history, **not evidence of current proficiency**.

See the [roadmap](docs/roadmap.md) and [workflow](docs/workflow.md).

University lab assignments live in a separate repository: [`cpp_labs`](https://github.com/arkpil60/cpp_labs).
